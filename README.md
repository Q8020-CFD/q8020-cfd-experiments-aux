# q8020-cfd-experiments-aux

Auxiliary code for the Q8020-CFD experiments: per-experiment helper scripts,
harvesters, plotting, and analysis utilities.

Split out of the `aux/` folder of
https://github.com/Q8020-CFD/q8020-cfd-experiments on 2026-10-15, with its
history preserved. The experiment definitions and results remain in that repo;
paths of the form `aux/<name>/...` recorded in its `results/` metadata refer to
`<name>/...` here.
